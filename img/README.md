# Fotos del sitio

La página busca cada foto primero en esta carpeta (`img/`). Si no la encuentra,
la carga desde Framer y, si tampoco está ahí, muestra el dibujo de la estructura.

- Para copiar aquí todas las fotos actuales: `bash tools/download-images.sh`
- Para cambiar una foto, sustituye el archivo manteniendo el mismo nombre
  (el nombre de cada foto aparece en `index.html`, variables `HERO`, `ABOUT` y la lista `P`).
- Tamaño recomendado: 2000 px de ancho, JPG con calidad ~80 %.
- `og.png` es la vista previa (1200×630) que aparece al compartir el enlace.
